# 数据格式与检查

[English](../en/data_contracts.md) · [简体中文](data_contracts.md)

清单文件描述预处理输入和训练数据，JSON schema 列出必需字段。加载器还会读取
关联数组，检查形状、坐标、电导率、电极顺序和单位是否匹配，并拒绝含 NaN 或 Inf 的数值数组。

| 文件格式 | 用途 |
| --- | --- |
| `prepared_subject_v1` | 预处理结果，供推理、FEM 和训练使用 |
| `fem_labels_v1` | 75 个源电极的 FEM 标签，供训练使用 |
| `training_loss_statistics_v2` | 50/100 mm 分区的能量统计 |
| `training_dataset_v1` | 训练数据路径及训练、验证、测试分组 |

字段定义见 [schema](../../schemas/)，目录结构见[输入格式说明](input_contract.md)。
每个文件路径相对于所属清单填写。加载器会检查路径是否安全、文件是否存在，以及实际大小与记录是否一致。

预测、FEM 标签和训练统计中的查询行与源电极顺序应保持一致：

- 查询点顺序以 `gmwm_ijk` 为准；源电极顺序是移除 Oz 后的电极列表。
- FEM 导出保存 `query_ijk.npy`，并与预处理查询点逐项比较。
- 能量统计 NPZ 保存查询点、affine 和电极坐标，加载时与输入数据比较。

加载时还会核对电导率表的全部数值和单位。FEM 检查包括电流、向量分量、HDF5
元数据和求解器实际使用的电导率。恢复训练时，保留已保存的配置、分组和数据路径。
旧版清单中保留的可选摘要字段不参与这些检查。
