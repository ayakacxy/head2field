# 评估与可重复实验

[English](../en/paper_reproduction.md) · [简体中文](paper_reproduction.md)

设计实验或报告结果时，可按本指南记录数据划分、训练统计、FEM 对比和运行时间。操作命令见[训练说明](training.md)，预测 API 见[推理说明](inference.md)。

<a id="manuscript-results"></a>

## 论文结果

当前[论文](../CITATION_GUIDE_zh.md)评估了 WU-Minn HCP 的 200 名健康成人，年龄为 22–36 岁，
来自 163 个家系。按家系划分（seed 42）后，训练、验证和测试分别为 128、32 和 40 人。
嵌套训练子集为 10、20、40、80 和 128 人，验证集和测试集固定。
每名受试者包含 75 个 source→Oz 电场，在 GM/WM 上评估。

| 实验 | 报告结果 |
| --- | --- |
| 训练规模 | 10、20、40、80 和 128 人训练时，平均全场相对 L2 误差分别为 0.118、0.098、0.082、0.078 和 0.070 |
| 物理正则化 | 不使用和使用正则化时，全场误差分别为 0.078 和 0.070，高场误差分别为 0.080 和 0.071；分别有 39/40 和 38/40 名受试者误差降低 |
| 高场幅值 | FEM 幅值第 90、95、99、99.5 和 99.9 百分位对应的队列保持率中位数分别为 0.992、0.991、0.986、0.984 和 0.978 |
| tDCS 合成 | 已训练/留出配置的平均全场误差：Head2Field 为 0.077/0.079，DeeptDCS 为 0.243/0.818 |
| TIS 包络 | 3,200 种配置的平均相对 L2 误差为 0.054，逐体素 Pearson 相关系数为 0.991 |
| TIS 规划 | FEM 评价下，FEM 优化和 Head2Field 优化方案的平均 H-WMFI 分别为 1.253 和 1.192；聚焦性保持率的几何均值为 94.9% |
| 未见电极位置 | 在 5、10、15 和 20 mm 位移处，无需微调的平均全场误差为 0.069–0.070 |

### tDCS 比较

两个模型均使用 80 名训练、32 名验证和 40 名测试受试者。Head2Field 每名训练受试者学习
75 个源到参考电极的电场，DeeptDCS 学习五个配置特异性电场。“已训练”和“留出”指配置是否
包含在 DeeptDCS 的监督中，每组各有五种配置；本次比较均未进行配置特异性微调。
所报告误差对应各方法各自的监督形式和损失设置。

### TIS 合成与规划

包络合成在每名测试受试者中使用 80 种配置：激活电极数为 4、8、16、32 或 64，每种数量
各 16 种配置，每个载波的正向电流总和为 1 mA。规划靶区为左侧内苍白球处半径 5 mm 的球，
限制在 GM/WM 内；避让区为排除靶区后的皮层和小脑 GM/WM 区域。优化器从 75 个候选电极中
选择 16 个，载波为 1,000 和 1,130 Hz，每个载波独立电流平衡，单电极绝对电流不超过 2 mA，
两个载波的绝对电流总和不超过 10 mA。两种基底均优化 3,000 个 epoch，seed 为 42。

H-WMFI 为靶区与避让区幅值之比。靶区项取靶区内最高 10% 包络幅值的均值；避让区项先剔除
超过该区第 99.99 百分位的幅值，再对剩余幅值中不低于剩余最大值 0.9 倍的部分取均值。

每个优化方案保持电极和电流固定，在两种基底上分别评价。FEM 复评时，Head2Field 优化方案
平均比 FEM 优化方案低 0.061（95% CI 0.031–0.091；Holm 校正 p = 0.001）。94.9% 为两种
方案均由 FEM 评价时，受试者层面 H-WMFI 比值的几何均值。在各自的优化基底上，两种方案
平均得分分别为 1.253 和 1.233（p = 0.256）。这些结果支持用预测基底快速搜索候选方案，
再用 FEM 评价选定方案。

### 电极位置泛化

40 名测试受试者均在五个锚点（F3、C4、P3、T8 和 PO7）周围，按四个方向和四种距离采样，
共得到 3,200 种独立 FEM 配置。复用锚点预测时，平均全场误差从 5 mm 处的 0.095 增至
20 mm 处的 0.273。输入实际坐标后，误差为 0.069–0.070，每个距离均有 40/40 名受试者改善。
直接预测在所有距离上的误差也低于对标准位置模型预测进行插值的结果。5 mm 处，FEM 库的
最近邻和测地插值基线误差更低；10–20 mm 处，Head2Field 的平均误差低于全部三种 FEM 库基线。

## 工作流程与实现

| 阶段 | 实现 | 配置或输出 |
| --- | --- | --- |
| T1 准备 | `preprocessing/`、`inputs.py` | `preprocessing_v1.json`；256³、1 mm RAS 网格 |
| 电导率与 FEM 标签 | `preprocessing/conductivity.py`、`fem_labels/` | `fem_labels_v1.json`；1 mA 下的 75 个 source→Oz 电场 |
| 解剖编码与电场预测 | `model.py`、`_spec.py` | `head2field_v1.json`；固定 v1 结构 |
| 能量归一化监督 | `training/cache.py`、`training/dataset.py`、`training/losses.py` | 完整电场统计；50/100 mm 分区；权重 0.60/0.30/0.10 |
| 积分物理损失 | `training/physics.py`、`training/physics_data.py`、`training/steps.py` | 仅使用训练集校准；四项权重均为 5；10,000 步递增 |
| epoch 训练与验证 | `training/runner.py`、`training/validation.py`、`training/cli.py` | AdamW；最多 25 个 epoch；余弦调度；patience 5 |
| 完整基底推理 | `inference.py`、`cli.py` | 有序 `[75, Q, 3]` float32 输出，world-RAS，单位 V/m |

上表的源码路径相对于 `src/head2field/`。配置文件位于 `configs/`，wheel 中也包含相同文件。

## 训练配置与衍生数据

真实数据配置为 `configs/training_v1.json`，合成安装配置为 `configs/training_smoke_v1.json`。两者使用相同的近、中、远分区：

```text
rho = min(distance(query, source), distance(query, Oz))
near: rho < 50 mm
middle: 50 mm <= rho < 100 mm
far: rho >= 100 mm
```

能量统计应在查询分块前，根据每个被试的完整 FEM 电场计算。分母下限使用该被试内部有效源电场的中位数。物理校准只用训练被试拟合，再原样用于验证和测试被试。

每步数据损失使用缩放 `M / (75 * N_train)`，其中 `M` 为一个完整训练 epoch 的全部源/查询组合数，也包含末尾不完整批次。验证和测试沿用训练分区的缩放。修改径向分区或训练划分后，应重新计算统计量。

加载器检查预处理数据、FEM 标签、目标缓存和物理采样数据的格式与数值。继续已保存的训练时，需要相同的配置和数据集记录；只加载推理权重则会重新初始化优化器和训练状态。

## 数据划分与评估

将各组分别分配给训练、验证或可选的测试分区，分区之间不能重叠。研究设计有此要求时，将有关联的参与者放入同一组。实验记录应保存分组、随机种子、预处理设置和权重校验值。输入数据集及参与者清单需另行获取。

按查询行和源电极匹配预测与 FEM 向量，确认坐标系、电流约定和单位一致后，再计算完整电场指标：

- 在匹配向量上计算相对 L2 误差和平均方向余弦。
- 根据 FEM 幅值确定高场掩膜，记录分位数阈值及等于阈值时的处理规则。
- 先在每个被试内平均源误差，再计算被试之间的平均值。
- 幅值保留率先计算各被试内部的源中位数，再报告队列中位数和被试 P10–P90。

单个分块上的训练诊断不能直接作为完整电场指标。报告每项指标时，应说明使用的聚合方式和掩膜。

安装包包含一份预训练 state dictionary。比较数据划分、训练规模、随机种子、消融或基线模型时，应为每种设置分别训练并评估权重。合成示例只用小模型检查软件流程，不测量预训练模型的精度。

## 运行时间测量

论文的代表性基准使用一张 RTX 2080 Ti 和 128 人训练模型，完成预热并启用 PyTorch 编译。
在 1,392,017 个 GM/WM 体素上预测完整 75 列基底，含设备到主机传输为 8.928 s；计入 float32
输出写入与刷新后为 12.073 s，即 0.201 min。

| 计时范围 | SimNIBS | Head2Field | 加速比 |
| --- | --- | --- | --- |
| 输入已准备好的导联场生成 | 约 20 min | 0.201 min | 约 100 倍 |
| 估计端到端流程 | 约 94 min | 约 20 min | 约 4.7 倍 |

Head2Field 的端到端估计在基底生成耗时上加约 20 min 分割时间，并取整到分钟。发布版预测
CLI 使用 FP32，未启用 PyTorch 编译；预处理命令运行完整 SimNIBS `charm` 头模型流程，
包括表面重建和网格生成。预测本身读取准备好的体素输入和电极坐标。测量发布版命令时，
分别记录这些阶段的耗时。

每项计时结果应附上硬件、软件版本、查询数量、分块大小和执行模式。分别记录输入加载、预处理、模型加载、实际使用的编译步骤、预热、推理、设备到主机传输和输出 I/O。

GPU 计时前后应进行 CUDA 同步。冷启动与复用模型或被试缓存的重复运行分别报告，并注明是否计入输出写入和刷新。端到端时间应覆盖所述流程需要的全部阶段；比较先导场推理本身时，单独报告该阶段。

## 结果使用

可以使用预测基底或 Python 查询接口编写电场合成与评估程序。电流优化、队列统计和绘图由应用程序处理。派生结果应与基底清单、源电流、查询坐标、权重文件名和校验值一同保存。用途与局限见[模型说明](../MODEL_CARD_zh.md)，参考文献见[引用指南](../CITATION_GUIDE_zh.md)。
